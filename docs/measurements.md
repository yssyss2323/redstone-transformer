# 마인크래프트 실측 지연 기록

모든 값은 게임 틱(1초 = 20틱). 레드스톤 가루나 토치 기준으로 측정 (램프는 꺼질 때 +4틱).
환경: Minecraft Java 26.3, `/tick freeze` + `/tick step 1`.

## 기본 게이트

| 부품 | 지연 | 비고 |
|---|---|---|
| NOT (토치 1단) | 2 | 램프로 재면 꺼질 때 6 |
| OR (가루 합치기) | 0 | |
| AND (토치 2단) | 4 | 켜지는 방향 기준 |
| 리피터 | 2 | 1단 설정 |

## 전가산기 v2

| 경로 | 지연 |
|---|---|
| Cin -> Cout | 8 |
| A -> S | 10 |
| Cin -> S | 6 (8비트 덧셈기 측정에서 역산) |

입출력: A, B 아래 / S 위 / Cin 오른쪽 / Cout 왼쪽 (같은 줄), 칸 사이는 가루 연결.

## 8비트 리플 캐리 덧셈기 (adder8_v1)

| 측정 | 지연 |
|---|---|
| 최악 올림 (A=11111111, B=0, Cin 0->1) -> Cout | 64 |
| 같은 조건 S7 (1->0) | 62 |

덧셈 시간 공식 (이 전가산기 기준): n비트 = n x 8틱.
