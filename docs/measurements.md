# 마인크래프트 실측 지연 기록

모든 값은 게임 틱(1초 = 20틱). 레드스톤 가루나 토치 기준으로 측정 (램프는 꺼질 때 +4틱).
환경: Minecraft Java 26.3, `/tick freeze` + `/tick step 1`.

## 기본 게이트

| 부품 | 지연 | 비고 |
|---|---|---|
| NOT (토치 1단) | 2 | 램프로 재면 꺼질 때 6 |
| OR (가루 합치기) | 0 | |
| AND (토치 2단) | 4 | 켜지는 방향 기준 |
| 리피터 | 2 | 1단 설정 |

## 전가산기 v2

| 경로 | 지연 |
|---|---|
| Cin -> Cout | 8 |
| A -> S | 10 |
| Cin -> S | 6 (8비트 덧셈기 측정에서 역산) |

입출력: A, B 아래 / S 위 / Cin 오른쪽 / Cout 왼쪽 (같은 줄), 칸 사이는 가루 연결.

## 8비트 리플 캐리 덧셈기 (adder8_v1)

| 측정 | 지연 |
|---|---|
| 최악 올림 (A=11111111, B=0, Cin 0->1) -> Cout | 64 |
| 같은 조건 S7 (1->0) | 62 |

덧셈 시간 공식 (이 전가산기 기준): n비트 = n x 8틱.

## 8레인 비트 직렬 내적 장치 (engine_8lane_v1)

구성: 레인 8개(AND 게이트 줄), 12비트 덧셈기 7개 사슬, 16비트 누산 덧셈기, 16비트 레지스터(리피터 잠금 플립플롭), 2배 되먹임, 첫 바퀴 XOR 반전기 + Cin.

- 음수 처리: 레인마다 비트 7 NOT, 사슬 맨 아래 단 A 입력에 상수 −1024 (`1100 0000 0000`, 비트 10·11)
- 레인 입력은 8비트만 사용. 비트 8~11에 값을 넣으면 음수 처리가 두 번 되어 틀림
- 한 바퀴 기다리는 시간: 수동 운영 시 약 20~30초 (정밀 측정 전)

### M1 검증: Q[0] = 33

- X = [2, 0, 3, −3, −7, 5] (위치 4 임베딩), Wq 0번 열 = [2, −3, −5, −1, −3, 4]

| 바퀴 | 켠 제어 | S | Q |
|---|---|---|---|
| 1 (−8 자리) | c1 c2 c3 c4 | −7 | 7 |
| 2 (4 자리) | c1 c3 c4 c5 | −5 | 9 |
| 3 (2 자리) | c0 c2 c3 | 2 | 20 |
| 4 (1 자리) | c1 c2 c3 c4 | −7 | **33** |

## M2: Q 벡터 자동 계산 + 저장 (engine_m2)

### 순서 장치
- 플립플롭 타일: 링용으로 4칸 높이 타일 사용 (3칸 설계 대신)
- 클록 순서: 버튼 → 누산 레지스터(먼저), 버튼 → 최대 지연 리피터 5개(40틱) → 4칸 링, 24칸 링
  - 누산 레지스터 클록 선에 리피터 16개 → 비트 15는 약 32틱 늦게 받음. 링은 그보다 늦어야 함
- 24칸 링 클록은 23번 칸 쪽에서 들어감 (데이터 반대 방향). 되돌림 선에 리피터 넉넉히
- 세팅: "1 넣기" + 클록 24번 → "링 연결" 끄고 클록 1번 → "링 연결" 켬

### 레지스터 층
- 5층 유리 바닥, 6층 래치, 7층 잠금선 (버스 칸 위에서만 8층 다리)
- 쓰기 신호: 버튼 → (링 쪽 지연 5개 뒤에서 가지) → 최대 지연 리피터 7개 추가 (합계 약 96틱) → 블록 + 토치로 뒤집기
- 잠금선 = 뒤집은 쓰기 신호(리피터) OR ROM 줄 끝 신호(리피터). 레인 0~5 ← ROM 4, 8, 12, 16, 20, 0번 줄
- 쓰기 버스: 누산 레지스터 Q에서 되먹임 AND 게이트 전에 갈라짐, 6층으로 레지스터 층까지

### 겪은 문제와 원인
| 증상 | 원인 | 해결 |
|---|---|---|
| 같은 줄이 바퀴마다 맞았다 틀렸다 | 회로 일부가 시뮬레이션 거리 밖이라 멈춤 | 회로 가운데에 서서 돌리기, 시뮬레이션 거리 늘리기 (`/forceload`도 가능) |
| 전부 끔인데 S가 0이 아님 | 레인 입력 비트 8~11에도 값을 넣음 (음수 처리 두 번) | 레인은 8비트만 넣기 |
| 1레인 단에서 −128 오차 | 1레인 단의 비트 7 NOT 누락 | 비트 7 게이트 뒤 NOT 추가 |
| 버튼 8에서 Q 비트 7만 틀림 | 되먹임 선(레지스터 비트 6 → 덧셈기 비트 7)의 토치 하나 빠짐 | 토치 복구. `rom_gen.py --run`의 A 입력으로 추적 |
| 래치 시험에서 버스와 잠금선이 같이 켜짐 | 버스 가루와 옆 블록 위 잠금선 가루가 계단 모양으로 이어짐 | 버스 칸 위 7층에 블록 (잠금선은 그 위 8층으로 넘어감) |

|---|---|---|
| 0 | 33 | 0010 0001 |
| 1 | −4 | 1111 1100 |
